# Speech-mouth comparison

`mouth-comparison.png` and `mouth-comparison.webm` show the owning BotPixel build with preset 1 (the same saved face used for the real DSH Grace reading qualification). The static comparison is half-open / legacy full opening / version-2 full opening, at 96px and 192px. The continuous silent recording plays both versions at an identical fixed preview cadence.

This is an isolated source-generated preview, not a real DSH runtime or performance measurement. Only version 2's fully open layer changes: five pixels wide and two rows high, with the bottom row narrowing to three pixels. The horizontal center matches the old three-by-three opening. Half-open, closed, saved and default/version-1 output remain identical, including head-turn layers. No recipe or golden fixture migration is involved. Real DSH integration qualification is recorded separately when available.
